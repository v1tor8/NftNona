# NftNona

NftNona is a high-performance, cloud-based data processing engine that utilizes real-time data ingestion and auto-scaling.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftNona.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

NftNona is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
